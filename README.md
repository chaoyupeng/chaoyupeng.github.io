# Yupeng's homepage

A single-file portfolio published with GitHub Pages at <https://chaoyupeng.github.io/>.

Edit `index.html` to change the design or copy. The project cards list public, unarchived repositories from the GitHub API; if the API is unavailable, the page shows the four repositories included in the HTML.

To preview locally, run `python3 -m http.server` in this directory and open <http://localhost:8000/>.
